# MappiBot — транспорт Києва в Telegram

Особистий бот для себе та друзів. Основне місто — Київ; пошук зупинок працює по відкритій карті України там, де вони нанесені. Це перша робоча версія: пошук, картки зупинок, маршрути зі схеми OSM, обране та експериментальні GPS-позиції Києва.

## Що вже є

- Кнопка «Зупинки поруч»: до 8 найближчих зупинок у радіусі 800 м.
- Пошук київського місця звичайним повідомленням; `/city вокзал, Львів` — пошук іншого міста.
- Зупинка як точка на карті Telegram, її маршрути з OpenStreetMap, збереження в обране.
- `/live` або `/live 104`: свіжі GPS-позиції Києва, якщо вони є у джерелі.
- Приватний доступ за посиланням-запрошенням, до 20 обраних зупинок, `/forget` для видалення збережених даних.

**GPS Києва має неповне покриття.** Офіційне джерело під час перевірки містило багато аномальних координат. Бот відкидає машини поза заданими межами Києва, без власного timestamp, зі старими або явно майбутніми показаннями. Координати і час проходять перевірку; це не незалежне підтвердження фактичної роботи рейсу. Прогнозів прибуття й пошуку A→B у цій версії немає.

Публічний номер маршруту береться з `vehicle.vehicle.label`: саме це значення пояснене розпорядником київського набору. Якщо його немає, технічний ID позначається окремо. Дані OSM про маршрут не підтверджують, що він зараз працює.

## Запуск

Поточний спосіб роботи — локально на Windows-ПК. Поруч із папкою репозиторію підготовлені `Start-MappiBot.cmd` і `Stop-MappiBot.cmd`. У репозиторії їхні переносні аналоги — `scripts/start-local.ps1` і `scripts/stop-local.ps1`. Скрипт старту зберігає токен через Windows DPAPI у каталозі runtime, передає його Node через середовище і не відкриває зайве вікно. Після перезавантаження ПК запуск ручний; автозапуск і зміни режиму сну не налаштовувалися. Під час сну ПК бот не відповідає.

Node.js 24 LTS рекомендовано. Код і залежності зберігаються на GitHub. Для цілодобової роботи потрібен постійний процес на комп’ютері або VPS; GitHub Pages не запускає цього бота.

```sh
npm ci
cp .env.example .env
# Заповніть .env локально: TELEGRAM_BOT_TOKEN, INVITE_CODE
npm test
npm start
```

На Windows файл можна скопіювати командою `Copy-Item .env.example .env`.

Створення випадкового коду запрошення:

```sh
node -e "console.log(require('node:crypto').randomBytes(24).toString('base64url'))"
```

Запрошення: `https://t.me/USERNAME_БОТА?start=ВАШ_INVITE_CODE`. Передавайте його тільки своїм друзям. Інший спосіб — задати числові `ALLOWED_USER_IDS` через кому; команда `/id` працює без доступу. Бот відповідає лише в особистих чатах і не робить розсилок.

Усі параметри описані в [.env.example](.env.example). Токен і код запрошення не комітити. `.env`, дані користувачів і журнали виключено з Git і Docker-образу. Токен бота не потрібен для CI.

Інструкція цілодобового запуску: [docs/deploy.md](docs/deploy.md).

## Відкриті джерела та їхні правила

Для малого особистого бота свідомо обрано Nominatim для завершених пошукових запитів. **Перед запуском прочитайте [Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/): максимум 1 запит/секунду сумарно для всього застосунку, обов’язкові ідентифікація застосунку, атрибуція і кеш; автодоповнення, масовий збір та надсилання конфіденційних даних заборонені.** Код обмежує запити інтервалом 1100 мс, кешує результати й дозволяє заміну URL без зміни коду. Запускати тільки одну копію бота. Цей публічний сервіс не є базою для масштабного геокодування.

Зупинки й маршрути: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL. Overpass використовується лише для малих запитів за дією користувача, з кешем; [обмеження публічних серверів](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html). Для масштабування потрібен власний або відповідний керований сервіс.

GPS: [портал відкритих даних Києва](https://data.kyivcity.gov.ua/dataset/dani-pro-mistseznakhodzhennia-miskoho-elektrychnoho-ta-pasazhyrskoho-avtomobilnoho-tra-dep-transport). Опублікований endpoint використовує HTTP. Через це транспортні дані не мають гарантії цілісності TLS; секрети та дані користувача туди не надсилаються. Інтеграція EasyWay поки не підключена.

## Дані користувача

На диску: Telegram ID допущених користувачів, явно збережені обрані зупинки й offset обробки повідомлень. Історія пересувань та повідомлення не записуються. Тимчасові результати й координати зберігаються в пам’яті; кнопки пошуку дійсні до 15 хвилин. Кеш провайдерів обмежений за кількістю записів. Координати для пошуку зупинок передаються Overpass, текст пошуку — Nominatim, картки — Telegram. Не надсилайте у пошук конфіденційну інформацію.

`/forget` видаляє профіль і обране та очищає тимчасовий стан. Якщо ID внесений адміністратором у `ALLOWED_USER_IDS`, право доступу залишається у конфігурації. Повідомлення у самому Telegram видаляються засобами Telegram.

## Перевірка й розширення

```sh
npm run check
npm test
npm run smoke
```

`smoke` робить невелику кількість реальних читань публічних джерел. Тести використовують штучні фікстури, відокремлені від робочих даних.

Структура: `src/bot.mjs` — сценарії Telegram, `src/providers.mjs` — OSM та резервний адаптер Дніпра, `src/kyiv.mjs` — київський GTFS-RT, `src/telegram.mjs` — Bot API і polling, `src/store.mjs` — стан на диску. Адаптер Дніпра є в коді для подальшого розширення, але не увімкнений у меню.

Результат дослідження EasyWay, обмеження й наступні кроки: [docs/research.md](docs/research.md).
