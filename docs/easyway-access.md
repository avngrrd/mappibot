# Підключення EasyWay API

Адаптер підготовлений. Без окремих облікових даних EasyWay стан залишається «не підключено». Telegram-токен для цього не підходить.

Доступ запитується через **info@eway.in.ua**, адресу на [офіційній сторінці API](https://www.eway.in.ua/ua/api). EasyWay просить зазначити міста, функції та спосіб використання. Ціну, ліміти, права на зберігання й показ даних погоджують індивідуально; підтвердженого безкоштовного тарифу для цього бота немає. Повідомлень EasyWay від імені користувача не надсилали.

## Готовий текст запиту

Тема: Доступ до EasyWay API для особистого Telegram Mini App у Києві

Добрий день!

Я створюю особистий Telegram-бот і Mini App для себе та невеликого кола друзів. Застосунок уже показує карту громадського транспорту Києва, відкриті маршрути, зупинки, частковий GPS та варіанти проїзду. Хочу доповнити його даними EasyWay, зокрема прогнозом прибуття й актуальними маршрутами. Зараз він працює на моєму Windows-ПК через тимчасову HTTPS-адресу. Код зберігається в GitHub; паролі та отримані транспортні дані туди не публікуватимуться.

Прошу повідомити умови доступу для міста `kyiv` до функцій:

- `general.GetSystemInfo`, `user.GetMyInfo`;
- `cities.GetRoutesList`, `cities.GetPlacesByName`;
- `routes.GetRouteInfo`, `routes.GetRouteToDisplay`, `routes.GetRouteGPS`, `routes.Search`;
- `stops.GetStopsNearPointWithRoutes`, `stops.GetStopInfo`.

Підкажіть, будь ласка, вартість, ліміти запитів, доступність GPS і прогнозів прибуття для Києва, вимоги до зазначення джерела та дозволений строк кешування. Чи дозволений описаний особистий Telegram Mini App із тимчасовим доменом? Як отримати login/password та актуальні приклади JSON-відповідей? Чи підтримує API передачу облікових даних через POST, щоб уникнути секретів у URL?

Дякую!

## Налаштування після отримання доступу

Додайте видані EasyWay значення у локальний `.env` у корені репозиторію:

```dotenv
EASYWAY_LOGIN=отриманий_логін
EASYWAY_PASSWORD=отриманий_пароль
```

`.env` виключений із Git. Не вставляйте ці значення в повідомлення бота, браузерні URL, командний рядок або публічні задачі GitHub. Сервер передає їх у задокументованому HTTPS-запиті; редиректи заборонені, повідомлення помилок не містять URL або оригінальних помилок сервера.

Ручна перевірка облікового запису без друку секретів:

```powershell
node --env-file-if-exists=.env scripts/check-easyway.mjs
```

`status()` перевіряє автентифікацію через `user.GetMyInfo`. Успішна автентифікація ще не підтверджує права на кожну функцію: після погодження доступу окремо перевіряють `routes()` для Києва, далі потрібні методи. До першої відповіді реального облікового запису транспортні JSON-відповіді не підключаються до інтерфейсу автоматично.

CLI друкує лише статус і розпізнані назви міст/функцій та числові ліміти. Повна відповідь, логін і пароль не друкуються. Код завершення `2` означає, що доступ не підтверджений. Після видачі облікового запису потрібні очищені від секретів приклади відповідей, щоб звірити GPS, маршрути й ETA із фактичною схемою JSON.

## Межі готового адаптера

`createEasyWay({login,password})` повертає `configured`, `status()`, `routes()`, `route(id)`, `gps(ids)`, `stop(id)`, `searchJourney(query)`. `route()` отримує опис, не геометрію; `GetRouteToDisplay` потребує додаткових позицій із каталогу/пошуку і в цей адаптер ще не включений.

Звичайна відповідь: `{method, city?, data, fetchedAt, source}`. `data` зберігає JSON сервера; це контракт серверного модуля, не публічного API Mini App. У документації назви контейнерів подекуди відрізняються від XML-прикладів, тому нормалізацію потрібно звірити з фактичним JSON після надання доступу. `gps()` приймає 1–5 числових ID й повертає `routes` із відповідями для кожного. ID EasyWay не є OSM ID або міським GTFS `route_id`.

`searchJourney()` приймає `start_lat`, `start_lng`, `stop_lat`, `stop_lng`, необов’язкові `transports`, `type`, `direct`, `results_count`. Типи: `bus,trol,tram,metro,train,boat`; спосіб: `optimal`, `fast`, `cheap`; до 25 варіантів. Поточне підключення обмежене Києвом.

Проміжок між мережевими запитами — щонайменше 1,1 с, черга обмежена. Кеш: GPS/табло 15 с, пошук 60 с, каталог 5 хв, опис маршруту 10 хв. Це технічні значення, які потрібно узгодити з умовами виданого доступу. Ліміт облікового запису може бути нижчим. Автоматичних повторів після помилки немає; відмова в доступі/перевищення квоти призупиняє нові запити на 60 с. Кешовані прострочені дані після збою не повертаються.

За [описом GPS](https://www.eway.in.ua/ua/api/routes.GetRouteGPS), `data_relevance=0` означає неактуальний збережений результат; це не live-позиція. Час `fetchedAt` є часом запиту, не timestamp машини. [Табло зупинки](https://www.eway.in.ua/ua/api/stops.GetStopInfo) містить `next_vehicle`/`second_vehicle`, якщо вони доступні; порожні поля не означають нуль хвилин.
