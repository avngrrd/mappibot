# EasyWay: перевірені сценарії та реалізація Mappi

Перевірено 12 вересня 2026 року на вебкарті Києва. Це перелік перевірених користувацьких сценаріїв, а не твердження про повне відтворення всіх можливостей нативного EasyWay. Власний інтерфейс Mappi не копіює назву, графічні ресурси, відгуки чи базу EasyWay.

## Що перевірено наживо

На [карті Києва](https://www.eway.in.ua/ua/cities/kyiv) відкрито каталог типів транспорту, вибір маршруту, GPS-фільтр і форму входу. У GPS-фільтрі є «Всі машини», «Низькопідлогові», Wi-Fi, кондиціонер. Контекстне меню точки пропонує A/B, маршрути в радіусі та посилання на адресу; дія «Маршрути в радіусі» відкрила перелік для 500 м. Форма входу пропонує Google, Facebook, Huawei та email; авторизація не виконувалася.

У [планувальнику](https://www.eway.in.ua/ua/cities/kyiv/compile) введено Контрактову площу та Ботанічний сад, обрано результати пошуку, відкрито варіант прямої поїздки автобусом 62. Видно піший підхід, посадку, вихід, тривалість, вартість, інтервал та посилання на друк. Перевірено налаштування видів транспорту, перемикання сортування, «без пересадок» та повторний пошук: у тестовому запиті кількість варіантів зменшилася з 25 до 2. Алгоритмічна оптимальність EasyWay цим не перевірялася.

На [сторінці автобуса 62](https://www.eway.in.ua/ua/cities/kyiv/routes/261) відкрито загальну інформацію, прямий і зворотний напрямки, зупинку «пл. Контрактова», розклад через піктограму календаря та відгуки. Перемикання буднів/вихідних і зупинки в розкладі змінює таблицю. На табло зупинки є розмежування GPS / розклад / інтервал. Посилання «Що поблизу?» у перевіреному стані не відкрило помітно нового вмісту. Друк, надсилання відгуку, соціальний вхід та купівля/платні функції не виконувалися.

## Відповідність сценаріїв

| Сценарій EasyWay | Стан Mappi |
|---|---|
| Карта Києва, масштабування, місце користувача | Є; геолокація за натисканням |
| GPS із номером маршруту | Є з міського GTFS-RT; покриття часткове, прострочені й аномальні координати відкидаються |
| GPS увімкнути/вимкнути; види транспорту | Є; фільтри карти незалежні від фільтра каталогу |
| Каталог, схема, зупинки маршруту | Є з OSM; до 4 схем одночасно |
| Прямий/зворотний напрямок | Наявні OSM-варіанти того самого номера, типу й перевізника; непідтверджений зв’язок не називається зворотним напрямком |
| GPS-машина → схема маршруту | Є; пропонує відповідні варіанти, а відсутню схему не вигадує |
| Зупинка → маршрути | Є за реальним OSM membership, з урахуванням об’єднаних platform/stop_position |
| Пошук адреси | Є за явним запитом; Nominatim не використовується для автодоповнення |
| Обрані маршрути/зупинки | Є на пристрої; зупинки звичайного бота зберігаються окремо на сервері |
| A→B з карти, пошуку, обмін точками | Є у вкладці «Поїздка» та через `/trip` |
| Пряма поїздка та пересадка | Є: до 1 пересадки на тій самій зупинці або через офіційний перехід метро |
| Піші підходи | Реальна геометрія OSRM; у разі збою явно позначається неперевірена відстань по прямій |
| Найшвидше/найдешевше | Не заявляється без часів рейсів і тарифів; натомість менше пересадок / менше пішки |
| Розклади | Є метро, кільцева електричка й фунікулер з офіційного GIS; наземні розклади ще не підключені |
| ETA першої/другої машини | Очікує на доступ до EasyWay та перевірку фактичних даних |
| Тарифи, оперативні зміни, доступність машини | Потрібне джерело з актуальними полями; є посилання на офіційні зміни Київпастрансу |
| Вхід | Підписаний Telegram initData та приватне запрошення |
| Відгуки EasyWay / рейтинг | Не перенесені; власної системи відгуків немає |
| Офлайн, push, друк поїздки | Не реалізовані |

Планувальник перевіряє напрямлений порядок OSM PTv2 і заборони посадки/висадки. Не створює зворотні напрямки розворотом масиву. Офіційна схема метро містить 52 станції й взаємні коди переходів; час переходу джерело не дає. Результат максимум із трьох варіантів не є вичерпним: наземні переходи між різними OSM-зупинками та поїздки з двома пересадками не шукаються.

## Перевірка реалізації

- Живі дані: Контрактова → Майдан автобусом 62; Контрактова → Дарниця метро через Майдан/Хрещатик. Піші підходи повернули геометрію й оцінку ходьби; часу руху транспорту немає.
- Через браузер: пошук обох точок, вибір метро, отримання пересадки й нанесення на карту; каталог розкладів, станція Контрактова площа, інтервали буднів/вихідних, електричка та фунікулер.
- Інтерфейс перевірено на настільному екрані та ширині 390 px. Це емуляція розміру iPhone, не фізичний тест iOS Telegram.
- Автоматичні тести перевіряють приватний доступ, HMAC, відкликання сесій, напрямки й ролі зупинок, переходи метро, геометрію ходьби, неповні джерела, межі запитів та приховування секретів.
- Повний запуск: 97 тестів пройшли. Перевірка синтаксису охопила всі 20 JS/MJS-файлів застосунку та скриптів.

## EasyWay API

[Офіційна документація](https://www.eway.in.ua/ua/api) вимагає окремих login/password; місто, функції й умови погоджують індивідуально. Підготовлено серверний адаптер, безпечну команду перевірки і [текст запиту доступу](easyway-access.md). Реальних облікових даних немає, запит від імені користувача не надсилався. До отримання доступу й прикладів JSON дані EasyWay автоматично в UI не підставляються.

Код не зберігає GPS/табло EasyWay у Git та не вбудовує облікові дані в Mini App. OSM ID, міський GTFS route_id та EasyWay ID є різними ідентифікаторами.
